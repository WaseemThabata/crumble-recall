# Crumble Recall

Play on your phone: https://waseemthabata.github.io/crumble-recall/

Crumb is a tiny ember lost on a frozen lake. Watch the ice glow, then hop him home from memory before the tiles melt. Scores go to a world leaderboard.

Test build by Waseem Thabata. The game is one HTML file. The leaderboard key inside it is a Supabase publishable key, which is meant to be public.
